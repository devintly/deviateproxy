# DeviateProxy

Проксирование сайтов через SOCKS/HTTP/HTTPS по пользовательским правилам с поддержкой импорта TXT/PAC списков.

Поддерживает **Firefox** (ПК и Android) и браузеры на базе **Chromium** (Google Chrome, Microsoft Edge, Opera и т.д.).

## Функции

- **Выборочное проксирование**: Создание пользовательских правил для проксирования или прямого подключения к доменам с поддержкой масок вида `*.example.com`, а также IPv4-адресов и диапазонов CIDR.
- **Профили серверов**: настраиваемый список прокси (SOCKS5, HTTP, HTTPS) с поддержкой авторизации.
- **Внешние и локальные списки**: Загрузка наборов правил по URL с автоматическим обновлением по расписанию (поддерживаются TXT и PAC-скрипты), а также ручной импорт из текстового файла.
- **Инспектор доменов вкладки**: отображение всех URL-адресов, загруженных сайтом, с переключением между обычным списком и иерархическим деревом поддоменов, а также добавлением правил в один клик.
- **Индикатор на иконке**: счетчик проксированных запросов для текущей вкладки.
- **Переключатель работы**: включение и отключение расширения одной кнопкой.
- **Локализация**: автоматическое переключение между русским и английским языками в зависимости от языка браузера.

## Структура проекта

```text
deviateproxy/
├── src/
│   ├── common/             # Общие ресурсы и логика (UI, иконки, парсеры списков)
│   ├── firefox/            # Манифест и скрипты для Firefox (Gecko)
│   └── chrome/             # Манифест и скрипты для Chromium (Chrome, Edge, Opera)
├── scripts/
│   ├── package.py          # Сборка пакетов (Python)
│   └── package.ps1         # Сборка пакетов (PowerShell)
└── .github/workflows/
    └── build-extension.yml # Автоматическая сборка в GitHub Actions
```

## Сборка

```bash
python3 scripts/package.py
# или в PowerShell (Windows):
powershell -ExecutionPolicy Bypass -File scripts/package.ps1
```

Результаты сборки сохраняются в папку `dist/`.
